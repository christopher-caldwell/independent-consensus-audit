# Reconciliation acceptance checklist

- Every source claim/question has a disposition.
- `not_observed` is not contradiction; `related` is not support.
- Non-omission relations cite source statements.
- Extraction retains one lineage per original document.
- Follow-ups remain outside the original denominator.
- Material objections remain visible and capped.
- Broad conformance has coverage; counterexamples stay narrow.
- Synthesis inferences cite premises and invent no votes/scope.
- Code calculates participation and confidence.
